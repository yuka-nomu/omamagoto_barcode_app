# おままごとバーコードアプリ 機能仕様書 v1.0

# 1. スキャン機能

## 概要

Code128バーコードをカメラで読み取り、商品情報を表示する。

---

## 入力

| 項目    | 内容         |
| ----- | ---------- |
| バーコード | Code128文字列 |

---

## 処理

1. カメラでバーコード読み取り
2. 商品情報検索
3. 商品名・価格をポップアップ表示
4. 合計へ加算
5. レジ音再生
6. 商品表示時間経過後ポップアップ非表示

---

## 表示仕様

| 項目     | 内容     |
| ------ | ------ |
| 商品表示位置 | 画面中央   |
| 商品表示形式 | ポップアップ |
| 表示時間   | 初期値3秒  |
| 合計表示   | 画面上部固定 |

---

## 制約

| 項目      | 内容                   |
| ------- | -------------------- |
| 再読み取り防止 | 商品表示中は同一バーコード再読み取り不可 |
| 対応形式    | Code128のみ            |

---

## エラー時

| 条件       | 動作          |
| -------- | ----------- |
| 未登録バーコード | 「みつかりません」表示 |
| カメラ権限なし  | 権限要求表示      |

---

# 2. 商品登録機能

## 概要

商品情報を登録し、保存時にバーコードを自動生成する。

---

## 入力

| 項目  | 必須 | 備考      |
| --- | -- | ------- |
| 商品名 | 必須 | 最大文字数未定 |
| 価格  | 必須 | 整数のみ    |

---

## 処理

1. 商品名入力
2. 価格入力
3. 保存押下
4. バーコード自動生成
5. 商品保存

---

## 制約

| 項目       | 内容            |
| -------- | ------------- |
| 価格       | 整数のみ          |
| ひらがなのみON | 商品名はひらがなのみ入力可 |
| 商品名       | ユニーク          |
---

## エラー時

| 条件     | 動作         |
| ------ | ---------- |
| 商品名未入力 | エラーメッセージ表示 |
| 商品名重複 | エラーメッセージ表示 |
| 価格未入力  | エラーメッセージ表示 |
| 数値以外入力 | エラーメッセージ表示 |

---

# 3. 商品一覧機能

## 概要

登録済み商品を一覧表示する。

---

## 表示仕様

| 項目   | 内容      |
| ---- | ------- |
| 表示形式 | 一覧表示のみ  |
| 並び順  | あいうえお順  |
| 検索   | 商品名部分一致 |

---

## 機能

* 商品検索
* 商品編集
* 商品削除
* 印刷対象選択

---

# 4. バーコード印刷機能

## 概要

選択商品のバーコードをPDF形式で出力する。

---

## 入力

| 項目  | 内容    |
| --- | ----- |
| サイズ | 小/中/大 |
| 部数  | 1以上整数 |

---

## サイズ仕様

| サイズ | 1ページ枚数 |
| --- | ------ |
| 小   | 24枚    |
| 中   | 12枚    |
| 大   | 6枚     |

---

## 処理

1. 商品選択
2. サイズ選択
3. 部数指定
4. PDF生成
5. 印刷共有

---

## 出力内容

* バーコード
* 商品名
* 価格

---

## 制約

| 項目      | 内容      |
| ------- | ------- |
| 用紙      | A4固定    |
| バーコード形式 | Code128 |

---

# 5. 会計機能

## 概要

読み取り商品の合計を表示する。

---

## 処理

1. スキャンごとに価格加算
2. お会計ボタン押下
3. 会計結果画面表示

---

## 会計結果画面仕様

| 項目   | 内容      |
| ---- | ------- |
| 合計表示 | 中央大表示   |
| 戻り操作 | 画面全体タップ |

---

## リセット仕様

| 条件     | 動作     |
| ------ | ------ |
| 会計画面終了 | 合計リセット |

---

# 6. 音再生機能

## 概要

スキャン成功時に音を再生する。

---

## 音仕様

| 項目    | 内容         |
| ----- | ---------- |
| 基本音   | レジ音        |
| ランダム音 | ON/OFF切替可能 |

---

## 処理

1. スキャン成功
2. 音選択
3. 音再生

---

# 7. 設定機能

## 設定項目

| 項目     | 内容     |
| ------ | ------ |
| ひらがなのみ | ON/OFF |
| ランダム音  | ON/OFF |
| 商品表示時間 | 秒数変更   |
| 音量確認   | テスト再生  |
| データ初期化 | 全データ削除 |

---

## 商品表示時間仕様

| 項目   | 内容 |
| ---- | -- |
| 初期値  | 3秒 |
| 変更範囲 | 未定 |

---
