# 1. ホーム画面

```text
┌────────────────┐
│ おままごとレジ │
├────────────────┤
│                │
│                │
│ [スキャン開始] │ ← 大ボタン
│                │
│                │
├────────────────┤
│ 商品管理  　　 │ ← 小さめ導線
│ 設定           │
└────────────────┘
```

## 方針

* 子どもが迷わずスキャン開始できる構成
* 保護者向け導線は目立たせない
* スキャン開始を最優先表示

# 5. スキャン画面

```text
┌────────────────┐
│ 合計：350円     │
├────────────────┤
│                │
│   カメラ表示    │
│                │
│   □□□□□□□□    │
│                │
│  ┌────────┐  │
│  │りんご    │  │
│  │100円     │  │
│  └────────┘  │
│                │
├────────────────┤
│   [お会計]     │
└────────────────┘
```

## 方針

* 商品名と価格は中央ポップアップ表示
* 子どもでも見やすい大表示
* 合計は常時表示
* 商品表示中は再スキャンしない
